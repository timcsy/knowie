# 提煉是每一層都在做的同一件事（Distillation Recurs at Every Layer）

> 母概念。整理的本質。
> 原名 `蒸餾`（名詞式）；2026-08-14 依「概念名字要是可拿來判文字的斷言」改名，見 [history/013](../history/013-概念命名從名詞式到斷言式.md)。

raw→精的提煉，在每一層遞迴出現：experience = 因果鏈的蒸餾、概念向上蒸餾成母概念、睡眠固化、整理 = 批次結晶、`history/` = 從 git 原始軌跡蒸餾（見 [記憶系統](記憶系統.md)）。同一個動作的不同尺度（fractal）。

## 三視角投影
- **規範**：整理是投影非分割（按概念蒸餾，不按類型分桶）；批次結晶 > 即時歸檔。
- **處境**：核心檔撐不住時，按概念下沉子目錄，增量更新摘要（不重讀全部）。
- **存在**：教訓——別預先設計概念/名字，等濃度夠了讓它結晶；命名是「認出已在用的私語」，不是發明（避開「沉澱」這類暗示已保留的詞）。

## 機制
- 下沉流（細節→後台）+ 上浮流（素材→蒸餾上 介面）的動態平衡。介面 的穩定 = 兩流的平衡態。
- 摘要是有損索引：導航時剪枝，到葉節點仍讀原文，別讓摘要替代內容。
- 對數加速的前提：摘要能**增量**更新 + 樹保持**平衡**（摘要失去區分力就分裂，像 B-tree node split）。
