## 這次快照對門檻的意義

原本的乾淨缺口是 `2.5% → 11.8%`（七庫）。現在健康側最高 6.8%、負債側最低 14.2%——**缺口位移了，但沒消失**，而樣本從 7 擴到 10。`~10%` 這個門檻在新分佈上仍然把兩群分乾淨。

負債側**換了一批庫**：原本的三個被修好，新的四個（battle / GeneralAffairs / trpc-design / cella）浮出來。這正是為什麼要釘 commit——同一批數字不會等你。

```bash

```

改寫 judge 的檢查條款後，**這張表的數字必須不變**。變了就是規格被動到了，不是措辭問題。
